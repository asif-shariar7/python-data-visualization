## Python Data Visualization

A collection of Python-based data visualization and interactive dashboards, covering exploratory data analysis, statistical plotting, comparative and multidimensional visualization, text visualization, time series analysis.

### Overview

This repository documents my journey through data visualization techniques using **Matplotlib**, **Seaborn**, **Plotly**, and **Dash**. It includes hands-on notebooks exploring core visualization concepts as well as fully built interactive dashboards using real-world datasets (Titanic and Smoothie Sales).

### Repository Structure

```
├── Comparative Visualization/     # Comparing categories and groups
├── Dashboard/                     # Interactive web dashboards built with Plotly Dash
├── Multidimensional Data Visualization/   # Visualizing high-dimensional data using t-SNE
├── Text Data Visualization/       # Word clouds from raw text and word frequencies
├── Time Series Analysis/          # Time series trends, moving averages, and seasonal decomposition
├── EDA.ipynb                      # Exploratory Data Analysis notebook
├── matplotlib.ipynb               # Matplotlib fundamentals & practice
├── seaborn.ipynb                  # Seaborn fundamentals & practice
├── my_plot.png                   
├── LICENSE
└── README.md
```
